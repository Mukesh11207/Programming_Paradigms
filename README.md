# Programming Paradigms Laboratory — CS203

A collection of laboratory programs, curriculum programs, and practice problems for the **CS203 Programming Paradigms Laboratory** course.

This repository is maintained for lab practice, concept understanding, and model lab exam preparation.

## 📚 Labs Covered

| Lab | Topic |
|---|---|
| Lab 1 | Data Types and Type Compatibility |
| Lab 2 | Scope of Variables |
| Lab 3 | Name and Structural Equivalence |
| Lab 4 | Arrays as Parameters |
| Lab 5 | Pointers and Function Pointers |
| Lab 6 | Parameter-Passing Methods |
| Lab 7 | Activation Records and Static/Dynamic Links |
| Lab 8 | Object-Oriented Programming |
| Lab 9 | Concurrency and Synchronisation |

## 📝 Curriculum Programs

The repository also includes the following curriculum programs:

- **CP1:** Type compatibility rules of a C compiler
- **CP2:** Scope of variables inside loops
- **CP3:** Name equivalence vs structural equivalence
- **CP4:** Passing large arrays by value vs reference
- **CP5:** Calling a function through a function pointer
- **CP6:** Pass-by-reference vs pass-by-value-result
- **CP7:** Activation records with static and dynamic links

## ⚙️ Compiling and Running

### C
```bash
gcc program.c -o program
./program
```

### C++
```bash
g++ program.cpp -o program
./program
```

### Java
```bash
javac Main.java
java Main
```

### Python
```bash
python program.py
```

For multithreading programs, use the required compiler options and language version specified in the source code or lab instructions.

## 🎯 Learning Goals

- Understand programming language concepts through practical implementation.
- Analyse variable scope, type compatibility, and equivalence.
- Practise pointers, arrays, and parameter-passing techniques.
- Understand activation records and procedure calls.
- Implement object-oriented programming concepts.
- Explore threads, semaphores, locks, and synchronisation.
